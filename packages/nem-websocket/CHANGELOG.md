# 変更履歴

このプロジェクトにおけるすべての重要な変更は、このファイルに記録されます。

変更履歴のフォーマットは[変更履歴の管理](https://keepachangelog.com/en/1.0.0/)に基づいています。

## [1.0.0] - 2026/08/10

### 追加

- `on`、`onConnect`、`onReconnect`、`onError`、`onClose` が解除関数を返すようにし、個別のリスナーと購読を安全に解除できるようにした。
- `host`、タイムアウト、再接続設定、チャネル名、アドレスを実行時に検証するようにした。
- 利用者 callback の例外を隔離し、接続状態の更新、購読復元、自動再接続が中断されないようにした。
- NIS1テストネットの実ノードへ接続するE2Eテストを追加した。

### 変更

- `onClose` は最後に登録した callback だけでなく、登録済みのすべての callback を呼び出すようにした。
- パッケージの安定公開 API を 1.0.0 として確定した。
- NIS1のアドレス系購読で使用するJSON payloadを公式形式に合わせ、アドレス登録と初期取得を再接続時にも復元するようにした。
- アドレス系チャネルではNIS1テストネットのcanonical表記を使用するようにした。

### 修正

- 無効なNEMアドレスが購読先やpublish payloadへ到達しないよう、長さ、Base32、network byte、checksumを検証するようにした。
- 接続先hostとWebSocket endpointの検証を接続前に行うようにした。

### ドキュメント

- テストネットE2Eテストの設定方法と実行方法をREADMEに追記した。

## [0.2.0] - 2026/07/23

### 修正

- WebSocket の異常切断時に接続状態、UID、購読ハンドルをリセットするよう改善。
- 未接続中に `off()` した購読が、後続の接続時に復元される問題を修正。
- 同一チャネルの複数コールバックを追跡し、再接続時の復元と `off()` による解除を正しく処理するよう改善。
- 重複する再接続タイマーの登録を防止。
- `timeout` と `ssl` の既定値の型ドキュメントを実装に合わせて修正。
- `@stomp/stompjs`、`ws` の依存バージョンを更新。

### ドキュメント

- ESM 専用パッケージとしての利用要件と、`off()` の解除範囲を README に明記。
- 公開 API の JSDoc に、接続・再接続・購読解除・エラー分類の実際の挙動を追記。
