# 変更履歴

このプロジェクトにおけるすべての重要な変更は、このファイルに記録されます。

変更履歴のフォーマットは[変更履歴の管理](https://keepachangelog.com/en/1.0.0/)に基づいています。

## [1.0.0] - 2026/08/10

### 追加

- `on`、`onConnect`、`onReconnect`、`onError`、`onClose` が解除関数を返すようにし、個別のリスナーと購読を安全に解除できるようにした。
- `host`、タイムアウト、再接続設定、チャネル名、アドレスを実行時に検証するようにした。
- 利用者 callback の例外を隔離し、接続状態の更新、購読復元、自動再接続が中断されないようにした。

### 修正

- `block` と `finalizedBlock` でアドレス指定を受け付けないようにし、誤った基底チャネルの購読・解除を防止した。
- 接続 callback の登録タイミングによって、同一接続イベントで callback が二重に呼び出される問題を修正した。
- 再接続後の新しい WebSocket 接続へ、既存の購読を正しく復元する処理を検証・強化した。

### 変更

- `onClose` は以前の callback を置き換えず、登録済みのすべての callback を呼び出すようにした。
- パースエラーの callback が未登録の場合は例外を送出せず、警告を記録して受信処理を継続するようにした。
- ブロック通知型に、REST のブロックヘッダーで提供される投票・ハーベスティング関連情報を追加した。
- パッケージの安定公開 API を 1.0.0 として確定した。

## [0.2.2] - 2026/07/23

### 修正

- 再接続前の接続タイムアウトが、新しい WebSocket 接続を誤って切断する問題を修正
- 再接続待機中に追加した購読が失われる問題を修正
- 接続完了前に `off()` した購読が、後から送信される問題を修正
- 利用者の通知コールバックが送出した例外を、JSON パースエラーとして扱う問題を修正
- 型定義の解決に必要な `@types/ws` を依存関係へ追加

### 変更

- `timeout` のデフォルト値 `10000` ミリ秒を実装に適用。`0` を指定すると無効化できます
- 同じ購読パスへの重複した subscribe メッセージを送信しないよう改善
- README と公開 API の JSDoc を、接続・再接続・購読解除の実際の挙動に合わせて更新

## [0.2.1] - 2026/01/18

### 変更

- 型エクスポートの整形（動作変更なし）

## [0.2.0] - 2026/01/14

### 追加

- `SymbolWebSocketError`型による構造化エラー処理
  - エラータイプの識別（`timeout`, `network`, `parse`, `connection`, `unknown`）
  - エラー重大度の分類（`fatal`, `recoverable`）
  - 接続先ホスト、再接続状態、再接続試行回数、タイムスタンプの情報
- エラーコールバック未登録時に`console.warn`で警告出力
- `isConnected`プロパティによる接続状態確認機能
- `close()`メソッドを`disconnect()`のエイリアスとして追加

### 変更

- `onError`コールバックの型を`WebSocket.ErrorEvent`から`SymbolWebSocketError`に変更
- fatalエラー（タイムアウトなど）発生時は自動再接続を停止
- 再接続時に古いWebSocket接続を明示的にクローズ

## [0.1.0] - 2025/12/29

### 追加

- Symbol ブロックチェーンのWebSocket接続サポート
- リアルタイムデータ取得（ブロック、トランザクション、アカウント情報など）
- サブスクリプション管理
- 自動再接続とサブスクリプション復元
- エラー・クローズイベントのハンドリング
