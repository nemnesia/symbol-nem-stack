# 変更履歴

このプロジェクトにおけるすべての重要な変更は、このファイルに記録されます。

変更履歴のフォーマットは[変更履歴の管理](https://keepachangelog.com/en/1.0.0/)に基づいています。

## [1.0.0] - 2026/08/11

### 追加

- TypeScript利用時に、購読チャネルに応じた通知型を `on()` / `off()` のコールバックへ適用

### 変更

- 再接続通知を伴わない切断時も、利用可能な別ノードへ自動切り替え
- ノード切り替え後に、登録済みの購読を自動復元
- `cosignature` 通知を `parentHash`・`signerPublicKey`・`signature` の組み合わせで重複排除

### 修正

- 接続初期化に失敗した場合に、作成済みの接続を残さず終了
- 1つの利用者コールバックが例外を投げても、他のコールバックの実行を継続

## [0.1.2] - 2026/07/23

### 修正

- 重複排除をチャネル・アドレス購読ごとに行い、同一トランザクションの別イベントを配信するよう修正
- 代替ノードがない場合に、接続を維持するノードをブラックリストへ登録しないよう修正
- 不正な接続数・キャッシュ設定・TTL・再接続設定を拒否する入力検証を追加

### 変更

- `@nemnesia/symbol-websocket` の依存下限を `^0.2.2` へ更新
- README と公開 API の JSDoc を実際の接続・購読・終了時の挙動に合わせ、オプション型と接続状態型をエクスポート
