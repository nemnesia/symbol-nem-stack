# Changelog

このファイルでは、`@nemnesia/nem-openapi-typescript-fetch-client`の変更履歴を記録します。

## [1.0.1] - 2026-01-12

### Added

- NEM NIS API Version 1.19のOpenAPI仕様から生成したTypeScript Fetchクライアントを追加
- アカウント、ブロック、チェーン、ノード、ネームスペース、トランザクションなどのAPIクラスを追加
- NIS APIレスポンスに対応するTypeScriptモデルを追加
- ESM形式のパッケージとして公開する構成を追加
