# Symbol NEM Interchange Format

TypeScript implementation of SNIF v1 Draft 2. The package creates, parses and verifies transport-independent Symbol and NEM interchange documents. Transport, storage, request lifecycle and node communication are intentionally outside its scope.

This package is a private pre-release while the normative fixture matrix is incomplete. It must not be published or described as SNIF-conformant until the Phase 3 gate in the specification is satisfied.

See [`doc/spec.md`](doc/spec.md) for the normative specification.
