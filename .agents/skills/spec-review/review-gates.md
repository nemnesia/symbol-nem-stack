# Review Gates

目的は、仕様書を完璧にすることではなく、現在承認されているスコープを実装・検証できる最小十分な品質に達しているかを判断することである。各ゲートは合格または不合格とし、不合格は必ず Critical の採用指摘に対応付ける。

ゲートは新しい要求を発見するためのチェックリストではない。各ゲートは既存のコンセプト、要件、仕様に対してのみ適用し、将来拡張や一般的ベストプラクティスを満たすためにスコープを広げてはならない。

## 品質ゲート

1. **目的と範囲**: 解決する課題、対象利用者、対象範囲、対象外を、現在のスコープを実装するために必要な範囲で一意に理解できる。
2. **機能と制約**: 既存要件が要求する機能、入力、出力、制約、および受け入れる結果を確認できる。要件にない追加機能や汎用化は要求しない。
3. **処理と例外**: 既存要件の実装・検証に必要な正常時の処理、状態または順序、失敗条件、例外時の結果を確認できる。理論上発生し得る全例外の網羅は要求しない。
4. **内部整合性**: 用語、要件、例、図表、関連資料の間に実装を妨げる矛盾がない。
5. **検証可能性**: 既存要件の受け入れ条件、境界条件、失敗条件を基に、独立して検証できる。追加の品質特性や将来ケースのテスト可能性は要求しない。
6. **不可欠な前提の現実性と安全性**: 現在のスコープの実装開始に不可欠な技術、運用、外部連携、法務、ライセンス、セキュリティ上の前提が未確認のまま残っておらず、確認済み資料と矛盾しない。より強固・高度・汎用的な方式が存在すること自体は不合格理由にしない。
7. **コンセプト・要件定義との整合性と前段品質判定**: 選択されたコンセプトシートと要件定義書がある場合、目的、対象ユーザー、提供価値、スコープ、判断原則、成功条件、前提条件、未決定事項、要件、制約および受け入れ条件が仕様書へ適切に引き継がれ、仕様設計を妨げる矛盾がない。対応するコンセプトレビュー結果がある場合は Review Result が「要件定義へ進める」、要件レビュー結果がある場合は Review Result が「仕様設計へ進める」であることを確認する。いずれかがブロック判定、または未解決 Critical で仕様設計の開始を妨げる場合は不合格とする。上流資料またはレビュー結果がない、対象不一致、または古い場合は Evidence Used に「未確認」と記録し、それだけを理由に不合格とはしない。開始を妨げない相違や Major/Minor は対応する重大度で記録する。

Gate 6 の技術的または安全性上の前提は、該当する場合に Reviewer C が承認済みの要件またはプロジェクト資料の関連箇所を選んで確認する。資料が存在しない、または範囲外で確認できないだけでは不合格にしない。前提が実装開始に不可欠で、確認が必要な理由と既存要求への具体的影響を示せる場合だけ不合格とする。

Gate 6 を根拠に、既存要求にない暗号強化、認証強化、冗長化、監査、監視、レート制限、リトライ、フォールバック、バックアップ、ローテーション等を予防的に追加要求してはならない。それらが必要なら、既存要件・仕様上の根拠と、それがないと現在のスコープを満たせない具体的影響を示す。

Gate 7 は Reviewer A が要件定義からの引継ぎ、Reviewer B がコンセプト・要件定義との価値およびスコープ整合性を適用する。Reviewer C は技術的または安全性上の前提に関係する場合だけ根拠を補足する。上流レビュー結果の Major/Minor は自動的に不合格にせず、仕様書への反映状況を確認する。

## 範囲外

コード構造、使用技術、ライブラリ、インフラ、UI、API の具体的な実装、データベース設計などの詳細は対象外とする。ただし、それらに依存する前提が上記ゲートを満たさない場合は、「採用する詳細」ではなく「確認または明確化が必要な前提」として扱う。

さらに、次は既存のコンセプトまたは要件で明示的に要求されていない限り範囲外とする。

- 将来拡張のためだけの予約領域、抽象化、プラグイン化、設定可能化
- 未要求の後方互換性、移行機構、フォールバック
- 未要求の運用機能、監査機能、管理機能、可観測性
- 想定スコープ外の利用者・環境・攻撃モデルへの対応
- 「念のため」に追加するエラー、状態、メタデータ、制約

## 判定と終了

- すべてのゲートが合格: **実装へ進める**。
- 1つ以上のゲートが不合格: **仕様の修正を優先する**。
- Major と Minor だけでは差し戻さない。

品質ゲートを満たした時点でレビューを終了する。より良い表現、代替案、残存 Minor、将来の改善余地を理由に継続してはならない。
