# Specification Reviewers

- **契約担当:** 適用範囲、主体、入力、出力、データ制約、状態、version、error、受け入れ条件を確認する。
- **上流整合性担当:** 承認済み要求と設計へ契約を追跡する。責任やアーキテクチャを仕様で新たに推測する必要がある場合は、上流の不足として報告する。
- **セキュリティ・相互運用性担当:** 承認資料と照合し、対象資産、認可、信頼境界、完全性、replay、失敗時の動作、外部標準、互換性を確認する。
- **検証担当:** 独立した実装者が適合性を判断できるか、例やtest vectorの出典を追跡できるかを確認する。

仕様に関係する観点だけを適用する。Checklistは要求の根拠にならない。重複指摘を統合し、承認済み契約が仕様段階へ委ねた実装上の選択は対象外とする。
