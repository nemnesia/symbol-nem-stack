# 基本設計の構成

既存の文書構成やユーザー指定を優先する。指定がなければ、対象に必要な章を次の順で整理する。

1. 概要、目的、適用範囲
2. 上流要求と設計原則
3. システムコンテキスト、外部主体、trust boundary
4. コンポーネントと責務
5. 依存方向と外部連携
6. 主要なデータフロー、状態、データ所有
7. 主要シナリオと失敗・復旧
8. セキュリティとプライバシー上の設計判断
9. 運用前提と品質・検証方針
10. 代替案、未決定事項、下流への引継ぎ
11. Traceability と参照資料

対象に不要な章は省略できる。本文と図の内容は上流要求および承認済み判断へ追跡可能にする。
