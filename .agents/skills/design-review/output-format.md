# Design Review Output

`../review-common/output-format.md` の共通構成を使い、このスキルの項目は次のとおりとする。

- **Finding ID:** 既存規則があればそれに従う。各指摘は設計箇所、適用される上流根拠、問題、影響、設計段階で必要な最小変更、完了条件を示す。
- **Review Result:** 対象レビュー方針が定める判定値を使う。
- **Domain Checks:** 要求追跡、コンテキスト、責務、依存方向、境界、データ所有、主要フロー、運用、セキュリティ、実装への引継ぎを扱う。適用外や未確認の重要範囲を明記する。
- **Review Gates:** `review-gates.md` の各項目と根拠を示す。

チェックリストそのものを正式 finding の根拠にしない。全項目を機械的に出力せず、確認に使った主要観点を要約する。
