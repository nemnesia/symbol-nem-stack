# Design Review Gates

各 Gate は `PASS`、`FAIL`、`NOT APPLICABLE` のいずれかで判定し、根拠を示す。チェックリストの項目だけを理由に Gate failure にしない。

1. **要求との整合:** 設計が承認済み目的、要求、制約と矛盾しない。
2. **コンテキストと責任:** 主体、コンポーネント、責務、trust boundary が明確である。
3. **構成と依存:** 構成要素、依存方向、データ所有が要求を成立させる。
4. **主要フローと状態:** 正常、失敗、復旧、ライフサイクルが責任境界を保っている。
5. **セキュリティと品質:** 適用される保護対象、認可、プライバシー、失敗時安全性、品質特性を設計で扱っている。
6. **実装可能性と引継ぎ:** 後続作業に必要な判断がある一方、委譲された詳細を不必要に固定していない。

Gate failure は、設計上の具体的な矛盾・欠落、影響、完了条件へ追跡する。下位工程で安全に選べる詳細が未決定であるだけでは差し戻さない。重大度と最終判定は対象スキルの既存方針に従う。
