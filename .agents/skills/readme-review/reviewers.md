# README Reviewers

依頼されたREADMEの範囲に必要な観点だけを適用する。

- **正確性:** 記述、version、command、例、サポート範囲を現在の実装と承認済み契約に照合する。
- **利用しやすさ:** 想定読者が前提条件と最初の利用手順を理解できるか確認する。
- **安全性:** 該当する場合に、security、privacy、credential、権限、errorに関する案内を確認する。
- **一貫性:** 複数文書が対象なら、意味、用語、リンク、サポート範囲を比較する。言語や読者が異なる文書に逐語一致は求めない。

指摘には該当箇所、根拠、読者への影響、確認できる修正条件を含める。好みや任意の説明不足だけを欠陥にしない。
