# Implementation Reviewers

次の観点を別々に確認する。変更に合わない観点は適用しない。

- **契約担当:** 動作、validation、状態、error、互換性を承認済み要求・仕様と照合する。
- **セキュリティ担当:** 関係する資産と信頼境界をたどり、認可、外部入力、秘密情報の露出、失敗時処理、具体的な攻撃経路を確認する。
- **データ・相互運用性担当:** encoding、精度、serialization、version、外部標準、必要に応じて独立したtest vectorを確認する。
- **品質担当:** 変更範囲の所有権、並行性、resource、error path、重要な結果を検出するテストを確認する。

各指摘には箇所、再現条件または確認事実、適用根拠、具体的な影響、完了条件を含める。チェックリストや実装方式の好みから製品要求を作らない。
