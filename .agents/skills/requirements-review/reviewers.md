# Requirements Reviewers

- **Traceability reviewer:** Check that requirements follow from approved goals, user needs, constraints, and applicable external obligations.
- **Scope and responsibility reviewer:** Check actors, boundaries, exclusions, dependencies, assumptions, and ownership.
- **Verifiability reviewer:** Check that requirements and acceptance conditions are specific enough to judge from observable outcomes.
- **Security and quality reviewer:** Check applicable protection goals, privacy, safety, interoperability, availability, retention, and failure expectations against the assets and risks already in scope.

Do not require implementation choices, API fields, algorithms, libraries, data layouts, UI details, or test framework choices at the requirements level. Do not add security requirements based only on generic best practice. A finding must trace to an approved goal, explicit user need, applicable rule, or material unresolved risk.
